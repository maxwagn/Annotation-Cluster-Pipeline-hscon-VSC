# Gouania pigra Genome Annotation Workflow

This repository documents a **complete genome annotation workflow** for *Gouania pigra*, starting from the ERGA **Annotato (Nextflow)** pipeline and extending into:

- BRAKER3 refinement  
- GeMoMa reference-based annotation  
- GeMoMa + BRAKER consensus  
- eggNOG functional annotation  
- Final renaming to reference genome coordinates  



## ⚠️ DISCLAIMER

This workflow is functional but not fully automated.  
Use it **at your own risk**.

- Some steps require **manual intervention**
- Intermediate failures may occur
- Outputs may need to be recovered manually



# OVERVIEW

The final annotation was generated by combining:

1. Annotato (Funannotate-based pipeline)  
2. BRAKER3 (RNA-seq + protein guided)  
3. GeMoMa (reference-guided; *G. willdenowi*)  
4. GeMoMa consensus merging (GAF)  
5. eggNOG functional annotation  
6. Final coordinate renaming  



# STEP 0 – EDIT `config.yaml`

Before running anything, update:

```bash
config.yaml
```

Make sure the following are correct:

- `species`
- `buscodb`
- genome path
- RNA-seq paths
- output directories (`outdir`, `tracedir`, `tmpdir`)



## Runtime + container settings (REQUIRED)

```yaml
runtime:
  max_cpus: 24

container:
  cache_dir: "/scratch/.../apptainer_cache"
  tmp_dir: "/tmp"

cleanup:
  remove_work: true
  remove_cache: false
  remove_pipeline: false
```



## BUSCO + DATABASE SETUP (CRITICAL)

The pipeline uses a **Funannotate database**, mounted to:

```bash
/opt/databases
```

You MUST define:

```yaml
funannotate_db_dir: "/path/to/funannotate_db"
```



### ⚠️ CRITICAL RULE

```bash
buscodb MUST EXACTLY match a folder in funannotate_db_dir
```

Example:

```yaml
buscodb: "actinopterygii_odb10"
```

Requires:

```bash
funannotate_db/actinopterygii_odb10/
```

If names do not match → pipeline WILL fail.



## BUSCO VERSION

Use ONLY:

- ✅ `odb10`
- ❌ NOT `odb12`



## Recommended: manual BUSCO download

cd /scratch/.../funannotate_db

# STEP 1 – SETUP PIPELINE

```bash
bash setup.sh <project_dir> <config.yaml>
```



## What `setup.sh` does

- creates directory structure  
- clones ERGA pipeline  
- creates `cluster_override.config`  
- sets container cache + tmp directories  
- **pre-pulls ALL containers**  
- validates Funannotate DB  
- binds DB to `/opt/databases`  
- patches Funannotate + BRAKER issues  



# STEP 2 – PREPARE INPUTS

```bash
bash prepare_annotato_inputs.sh <config.yaml> <annotato_inputs>
```

Creates:

```bash
annotato_inputs/params.json
annotato_inputs/rnaseq_input.csv
```



# STEP 3 – RUN ANNOTATO PIPELINE

```bash
cd software/pipelines/erga-pipelines/annotation/nextflow
```

```bash
module load Nextflow

nextflow run main.nf \
  -params-file ../../../../annotato_inputs/params.json \
  -profile local,singularity \
  -c ../../../../cluster_override.config
```



# STEP 4 – RESUME (IF FAILURE)

```bash
nextflow run main.nf \
  -params-file ../../../../annotato_inputs/params.json \
  -profile local,singularity \
  -c ../../../../cluster_override.config \
  -resume
```



# STEP 5 – BRAKER REFINEMENT

Modify config:

```yaml
run_braker: true
skip_all_masking: true
skip_functional_annotation: true
skip_rename: true
```
