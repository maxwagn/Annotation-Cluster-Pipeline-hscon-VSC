# Gouania pigra Genome Annotation Workflow

This repository documents a **full genome annotation workflow** for *Gouania pigra*, starting from the ERGA **Annotato (Nextflow)** pipeline and extending into:

- BRAKER3 refinement
- GeMoMa reference-based annotation
- GeMoMa + BRAKER consensus
- eggNOG functional annotation
- Final renaming to reference genome coordinates

⚠️ **IMPORTANT:**  
This workflow is functional but not fully automated.  
Use it **at your own risk**.

---

# OVERVIEW

The final annotation was generated by combining:

1. Annotato (Funannotate-based pipeline)
2. BRAKER3 (RNA-seq + protein guided)
3. GeMoMa (reference-guided; *G. willdenowi*)
4. GeMoMa consensus merging (GAF)
5. eggNOG functional annotation
6. Final coordinate renaming
